# 🚀 ZABON — Language Academy

> **Международная EdTech-платформа для изучения таджикского, русского и английского языков.**  
> **Основатель и архитектор:** JABORZODA FAYZALI

---

## 🌟 Особенности проекта

- 🇹🇯 **Тоҷикӣ | 🇷🇺 Русский | 🇬🇧 English** — полноценная поддержка 3-х языков как в учебных материалах, так и в локализации интерфейса (i18n).
- 📱 **Mobile-First & PWA** — адаптивный UX под мобильные устройства и десктопы, поддержка установки на главный экран смартфона и работа в офлайн-режиме через Service Worker.
- 🎴 **Интерактивные Flashcards** — 3D-тренажёр слов с оценкой сложности и начислением XP.
- 🎙️ **Speaking Trainer** — распознавание речи (Web Speech API) и произношение слов в реальном времени.
- 🌐 **ZABON Translator** — модуль перевода фразы между тремя языками с локальной базой знаний.
- 📊 **Прогресс и Геймификация** — подсчёт дней подряд (Streak), система XP, награды и статистика.

## 🛠️ Технологический стек

## 🚀 Пошаговая инструкция по публикации на GitHub Pages

1. **Создайте репозиторий на GitHub:**
   - Назовите репозиторий `zabon`.
   - Выберите статус **Public**.

2. **Загрузите файлы:**
   - Перенесите все файлы (`index.html`, `manifest.json`, `robots.txt`, `sitemap.xml`, `service-worker.js`, папки `css/` и `js/`) в репозиторий.

3. **Включите GitHub Pages:**
   - Перейдите в **Settings** -> **Pages**.
   - В разделе **Source** выберите ветку `main` (или `master`) и папку `/ (root)`.
   - Нажмите **Save**.
   - Ссылка на ваш сайт будет доступна по адресу:  
     `https://<ваш-username>.github.io/zabon/`

---

## 🔍 Подключение к Google Search Console

1. Откройте [Google Search Console](https://search.google.com/search-console).
2. Нажмите **Добавить ресурс** и укажите URL вашего сайта GitHub Pages.
3. Подтвердите владение с помощью мета-тега или загрузки HTML-файла проверки.
4. Отправьте файл Sitemap: добавьте ссылку `https://<ваш-username>.github.io/zabon/sitemap.xml` в раздел **Sitemaps**.
5. Нажмите **Запросить индексирование** для главной страницы.
